# 指导书三：轻量语义排版、切片与30题演示验收

生效日期：2026-11-17。本轮目标是可演示的铁路RAG知识库。取消Wiki建设，取消全部1202个知识点逐项模型复审、所有表格/原件逐页视觉检查、70题回归加至少10题留出、全量疑点闭环等旧交付门槛。已有结果保留复用，不倒退重做。

这份文件中的30题、抽样和延期规则取代旧标准；不得把本轮通过写成旧标准通过，也不得宣称全面正确或适合直接指导现场作业。

## 1. 语义预处理究竟做什么

只把原文整理成结构清楚、方便切片的Markdown：标题层级、章节、条款、段落、列表、可读表格及来源位置。默认保留原文措辞，不用模型重写整篇，不生成百科、扩写解释或跨文献结论。

一个规则的主体、适用条件、否定、例外、单位和必要引用应能一起理解。表格的表头、单位、行名、备注要能对应。原件留白写“原文未提供”，不补数值；抽取不清写待核对，不推断原文。

已有合格结构不改。新发现格式问题先用已有脚本修复；仅对难以识别的局部结构调用模型。文献主体与复杂附件可以分开处理，但延期附件须标记“部分覆盖”，不得作为18份完整文献之一。

## 2. 切片采用现成能力

沿用已验证的Markdown管道、嵌入模型和重排配置，不重新选择技术栈。按章节/条款及语义边界切片，保持来源标题和定位信息。来源必须能通过正文前缀或实际可回读元数据取到，不只存在本地登记里。

- 不为了统一字数切断条件、例外或表格备注；不要机械地把所有超过900 token的段落重切。
- 保持实际嵌入与重排输入预算内且不静默截断。已有已验证预算直接复用；没有依据时只核对当前配置和最长代表样本，不逐片重新调用远端tokenizer。
- 超长且难以拆开的复杂表格优先延期或替换文献，不为几张表开发新解析器。
- 目录、空片、纯文件索引不作为问答证据。现有启停/过滤机制能解决就直接使用。

## 3. 质量检查由全量语义审计改成抽样

全量检查只做便宜的确定性检查：空正文、重复文献、标题/条款明显丢失、来源定位缺失、解析失败和已有规则能识别的异常。已有通过记录且正文/管道未变时不重跑。

每份文献抽查5个实际业务切片（少于5个则全查）：开头、中间、末尾各1个，加2个含数值、条件、否定、例外或表格的切片；没有这些内容则另选2个。已有更充分的合格检查直接抵用，不再抽一次。

对照原文检查这5片的含义、条件、数值/单位、来源位置和可读性。普通清楚文本无需逐页渲染PDF，也无需第二个模型复审。只有疑似OCR错字或表格错位，才查看对应原页。

发现会改变意思的错误，检查并修复同类受影响切片，随后复查该类问题；不要只修被抽中的一片。若是系统性错误且短期无法修好，移出本轮正式范围并替补文献。抽查通过只是抽样结论，不代表每个知识点都核验过。

## 4. 问答约束提示词

在现有演示问答配置中使用下述约束，与已有引用格式要求合并，不凭空创造引用占位符：

> 你是铁路知识学习助手。只根据本次检索到且适用的文献回答，保留必要的主体、条件、例外、数值和单位。对关键结论使用系统真实提供的引用标识，让用户能定位原文，不编造文献、条号、链接或引用ID。资料之间存在版本或适用范围差异时明确说明，不能自行裁定现行效力。
>
> 如果证据不足，直接说明“当前知识库没有足够依据回答这个问题”，简短指出缺少什么资料，然后结束。不要用常识猜测数值、资格、认证结果或操作步骤，不在拒答后附加无来源的建议。原文留白不等于零或无限制。对只覆盖部分内容的文献，只回答已覆盖部分，不声称全文或当前全部规定均已核实。

只修正现有回答约束，不顺带开发新评判器或自动纠错智能体。

## 5. 固定30题，做一次真实验收

先从现有题库挑选并冻结问题、预期证据与判定标准，缺什么再补什么。不得看到结果后删除失败题或换成容易题。记录在一个结果文件即可，例如 `05-review/mvp-acceptance-2026-11-18.json`；日期使用实际执行日期。

| 类型 | 数量 | 要求 |
|---|---:|---|
| 五领域基础问题 | 20 | 每领域4题；配合后5题尽量覆盖全部18份文献 |
| 条件、例外、版本或跨文献问题 | 5 | 优先纳入已有暴露缺陷；至少2题检查条件/例外，跨领域仅在入口支持时选用 |
| 无证据或范围外问题 | 5 | 真实缺证据，检查不编造、不追加无来源答案 |

25道有证据题要覆盖全部18份文献的至少一个检索知识点；测试前若文献不在候选范围，替换的是未冻结的选题，不是测试后的失败结果。跨领域功能非必做，不支持则以同领域跨文献或条件题替代，并在测试前确定。

通过要求：

1. 18份完整文献真实入库，每库至少2份，每份来源与切片抽样符合本版要求，并至少一次实际检索成功。数量按指导书一去重，至少12份净新增。
2. 25道有证据题中至少20题回答正确且有实际支持结论的引用；报告真实分数，并给出各领域得分，每领域4道基础题至少3题通过。仅检索命中但回答错误不能算通过。
3. 5道无证据题全部正确表达依据不足，不编造答案，不追加无来源的实质性建议。
4. 测试中发现的伪造来源、关键数值/单位错误、条件颠倒和已知失效内容冒充现行依据，不能用总分抵消：必须修复并针对性复测，或移除相关内容并诚实报告覆盖不足。移除导致不足18份时需要替补，不能仍报数量达标。
5. 实际演示入口至少完成5次端到端问答，每领域1题，并能展示/定位引用。优先直接计入上述30题；底层脚本的结果不能代替入口验证。

测试用现有真实检索与生成服务，记录问题、预期来源、实际命中、原始回答、真实引用、通过/失败及一句原因；不能用预写答案代替。执行者核对这些回答与证据即可，不再对全部输出调用另一个付费模型评审。结果标明“开发验收小样本”，不冒充独立评测或泛化准确率。

最多一轮完整30题，再做一轮有针对性的修复复测；规则或提示词改变时复测所有受影响题型，包括全部5道拒答题，不只重跑最容易的一题。复测仍不达标就输出“演示版未完全通过”及具体阻塞，不无限迭代、不擅自继续花费。首次结果和复测结果都保留，不能覆盖失败历史。
